这个工具做什么、不做什么

  • 做：PEM ⇄ JKS ⇄ PKCS#12 三向往返，证书链整条带走，私钥一起打包；生成的 JKS 与 PKCS#12 都按标准格式写，能被 keytool、openssl pkcs12 直接打开。
  • 不做：不解析加密过的私钥（ENCRYPTED PRIVATE KEY 得先 openssl pkey 解开）；私钥转换目前只支持 RSA，EC / SM2 私钥请用 openssl pkcs12 -export；证书本身（含国密证书）不限算法。
  • 口令怎么填：源口令是打开输入文件用的（PEM 一般空着）；目标口令是生成出来的密钥库的口令，之后 keytool / 应用配置里用的就是它。
  • 为什么是纯前端：私钥一旦经过别人的服务器，就等于交出去了。这里全程 FileReader + 本地解码，浏览器关掉就什么都不剩。
  • 典型用途：阿里云 / 腾讯云下载的证书要换成 Tomcat 认的 JKS；老项目 .jks 想搬到 Nginx；Spring Boot 从 JKS 迁到 PKCS#12。
